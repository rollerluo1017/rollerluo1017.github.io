Suixue

边看英文网页和视频边积累单词。词典和词频表都内置在插件里，查词不联网，也不依赖 AI 服务。

  • 自适应词汇量测试，按你的水平决定哪些词算生词
  • 网页上的生词自动标黄，悬停看音标和释义
  • 划词加入单词本，同时记下原句和网址
  • 总结视频字幕里的高频词，支持 YouTube 和 B 站
  • 没有字幕时用本地 Whisper 模型听写
  • 单词本可导出 CSV，导入 Excel 或 Anki

Aizhi · philosophia

给哲学专业学生用的学习伙伴。用中文讲解，保留关键术语的原词，覆盖西方哲学、中国哲学、印度与佛教哲学。

  • 概念精讲：原词、问题语境、概念史、解读争议
  • 苏格拉底式对话：追问预设，站在对立面反驳
  • 原著导读：逐段带读你自己的 PDF，支持扫描版 OCR
  • 跨传统比较，测验复习，记录学习进度

    分支剧本编辑器

    branch-script-editor

    写分支游戏剧本的工具：主线、支线、大量选项、多结局。只有一个网页文件，双击就能打开。

    • 在画布上拖线连接节点，画出整张分支图
    • 选项可以带条件和效果，比如 好感 >= 3
    • 像玩游戏一样试玩，随时查看和修改变量
    • 自动找出死路、漏连的选项和走不到的节点
    • 模拟所有路线，列出每个结局能否达成
    • 导出 JSON 和朋友交换剧本，或导出 Markdown 文本
    HTMLJavaScript离线可用
